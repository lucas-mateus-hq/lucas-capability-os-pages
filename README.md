## Public artifact

**[Capability Evidence Protocol v0.1](public/protocol/CAPABILITY_EVIDENCE_PROTOCOL_v0.1.md)** is an experimental, model-agnostic protocol for separating capability claims from inspectable evidence, independent evaluation and promotion decisions.

It includes a machine-readable JSON Schema and an example receipt. The artifact is publicly inspectable, while private experimental systems, execution evidence and working materials remain private. No reuse license has been granted yet; licensing will be defined separately before the protocol is presented as open source.
