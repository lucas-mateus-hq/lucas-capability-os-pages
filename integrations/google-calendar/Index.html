HOW IT WORKS

One source of truth. One safe path.

1
Events live in GitHub

automation/calendar/events.json is the controlled input. Stable IDs make updates idempotent.

2
GitHub validates before sending

The workflow checks required fields, dates and duplicate IDs before it contacts this bridge.

3
This bridge authenticates the request

The shared token is required before any Calendar mutation. The browser UI cannot create or edit events.

4
Google Calendar is updated safely

Existing events are matched by a stable sync marker; otherwise a new event is created.

SECURITY BOUNDARY

What this page can and cannot do.

Read-only UI.The status view exposes only configuration booleans, target mode and timezone. It never returns the shared token, calendar ID, event titles, descriptions or participant data.

If this page says “Ready”, the Apps Script side is configured. GitHub repository secrets must still be configured separately before automated sync can run.
