# Visual redesign v2 — distinct surfaces and an editorial personal identity

2026-10-18. User rejected the preceding preview as visually unattractive and insufficiently differentiated. This revision changes composition and surfaces, not merely labels or test counts. It remains a candidate preview, not publication.

## Real portfolio comparison

Sources actually inspected through public pages and retrieved visual references:

- Tobias van Schneider, https://vanschneider.com/ and the author's visual account https://vanschneider.com/blog/introducing-the-new-hovs-website/ — personal identity can accommodate work, products and writing under one name. Adaptation: authored hierarchy and a large self-introduction; no borrowed artwork or copied branding.
- Dennis Snellenberg, https://dennissnellenberg.com/ — direct work/about/contact navigation, strong portrait and large typography. Adaptation: simpler personal navigation and a rectangular photo composition. No 3D, complex cursor or page transition dependency.
- Maggie Appleton, https://maggieappleton.com/ — a personal site can organize different kinds of thinking and making. Adaptation: space for learning/technology interests without pretending Lucas already has a published essay collection.

The comparison is design interpretation, not a controlled usability study. The user’s preference is the deciding aesthetic signal; passing automation is not evidence that a site is beautiful.

Body slate #263641 is retained. Ivory #eee9df, deep green #183d3b, pale sage #d9e2df and coral #f1b895 create clearly distinct bands. Main type pairs system sans serif with Georgia. No font download, new dependency, tracker, invented credentials, product screenshot or paid asset added. Product artwork is illustrative site typography, not a final cover or screenshot.

The English portfolio and privacy source/URLs remain. The shared header/footer/product detail inherit the new style. The product remains upcoming, without invented Hotmart URL or purchase control.

## Verification

Build and static checks; actual foreground/background pairs are tested for 4.5:1 normal text contrast. Real Chromium tests additionally assert that career, creation, ideas and contact surfaces are different from the body. Existing keyboard, no-JavaScript, text-spacing, all-route viewport, relay and desktop/mobile Lighthouse gates remain. The managed Work environment lacks control-browser; no local rendered visual audit is claimed. GitHub Actions runs real browser layout checks and captures. Human aesthetic approval and audience usability testing remain separate from automated validation.
